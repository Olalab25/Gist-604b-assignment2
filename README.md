# Gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects
QGIS Fundamentals: Mapping and Spatial Analysis
a. Overview
        This repository documents my hands-on learning experience through a series of QGIS tutorials focused on fundamental Geographic Information System (GIS)           concepts and practical geospatial analysis. The exercises demonstrate essential workflows, including map creation, coordinate reference system
        management, spatial data visualization, attribute analysis, and spatial queries. Through these tutorials, I developed practical experience working with
        vector and raster datasets, importing external data, performing table and spatial joins, and producing informative maps. The repository serves as a
        record of my technical development and a reference for applying open-source GIS tools to real-world geospatial projects.
b. Software Environment
        •	GIS Software: QGIS

d. Skills Demonstrated
        The tutorials provided practical experience in the following technical areas:
        •	Map Design and Cartography: Creating map layouts, legends, scale bars, and professional map exports.
        •	Coordinate Reference Systems: Understanding geographic and projected CRS, EPSG identifiers, and reprojection.
        •	Spatial Data Management: Loading, organizing, and managing vector and raster datasets.
        •	Attribute Table Operations: Exploring, filtering, selecting, and exporting features based on attribute values.
        •	Tabular Data Integration: Importing CSV and spreadsheet data into QGIS and creating geographic features from coordinates.
        •	Vector Symbology: Applying categorized and graduated styles to communicate geographic patterns.
        •	Raster Visualization and Analysis: Displaying raster datasets and interpreting raster values through visualization and analytical tools.
        •	Table Joins: Connecting spatial and non-spatial datasets using common attribute fields.
        •	Spatial Joins: Combining information from geographic features based on their spatial relationships.
        •	Spatial Queries: Selecting and analyzing features using geographic relationships.
        •	GIS Troubleshooting: Identifying and resolving common issues involving projections, data formats, and layer alignment.
        •	Geospatial Communication: Presenting spatial information through readable maps and reproducible GIS workflows.
e. Reflection
        Completing these QGIS tutorials strengthened my understanding of how different GIS concepts work together to support spatial analysis and cartographic
        visualization. Working directly with coordinate reference systems made the relationship between projections, geographic coordinates, and layer alignment
        much clearer, while the attribute and spatial join exercises demonstrated how geographic information can be integrated from multiple datasets. One of the         more challenging aspects was understanding the differences between table joins and spatial joins, particularly when determining which approach was
        appropriate for a specific analytical problem. Raster styling and spatial queries also required careful attention to data properties, analysis
        parameters, and the interpretation of results. Through repeated practice, I became more comfortable navigating the QGIS interface, using its processing
        tools, and troubleshooting common GIS problems. I anticipate applying these skills to geological mapping, mineral exploration, environmental assessment,
        and geospatial data analysis, where integrating multiple datasets and identifying spatial relationships are essential. Overall, these exercises
        reinforced the value of QGIS as an accessible, open-source platform for producing reliable spatial analyses and communicating geographic information
        effectively.
